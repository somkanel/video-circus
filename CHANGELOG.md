# Changelog

## 0.5.0 · 2026-10-08

First public release of the complete Video Circus suite.

### English

1. **Media import**: accept local files, supported video links, and web players, with media validation and a reusable media package.
2. **Video understanding**: combine captions, local multilingual speech transcription, and Agent-reviewed frames into content with timestamps and evidence.
3. **Reading reports**: deliver searchable HTML with chapters, transcript and frame lookup, plus Markdown and JSON.
4. **Agent setup**: install the full workflow or individual stages into Codex, Claude Code, and other Agent Skills-compatible Harnesses.

### 中文

1. **导入素材**：接收本地文件、受支持的视频链接与网页播放器，验证媒体并生成可复用的媒体包。
2. **理解内容**：结合字幕、本地多语言转写和 Agent 审阅的画面，生成带时间与证据的内容包。
3. **阅读报告**：交付可搜索的 HTML，支持章节、转写和画面回查，同时生成 Markdown 与 JSON。
4. **安装技能**：支持向 Codex、Claude Code 及兼容 Agent Skills 的 Harness 安装整套流程或单个阶段。

### Scope / 范围

This is an early release. Browser discovery and semantic review depend on the Harness; Windows, PDF pagination, and coverage of every video source are not verified. Local extraction and ASR do not upload video; Agent inference depends on host configuration.

这是早期版本。浏览器发现与内容审阅依赖宿主；Windows、PDF 分页及所有视频来源的兼容性尚未验证。本地抽帧与转写不上传视频，Agent 推理是否使用云端取决于宿主配置。

Suite version: `0.5.0`. Skill versions: `video-circus 0.1.0`, `circus-conjurer 0.2.2`, `circus-juggler 0.1.1`, `circus-ticket 0.1.0`.
