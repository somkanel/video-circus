# 🎪 Video Circus

给用户一条从视频到阅读报告的路径。首条说明与最终交付以 🎪 开头；进入获取、理解、交付阶段时分别用 🎩、🤹、🎫 标识。阶段间沿用已有授权，不重复询问是否继续。

## 选择起点

明确调用本技能且给出URL/文件，默认执行完整流程，报告语言跟随用户。已有上下文中的范围、目标读者和格式优先；未指定时生成分层HTML阅读报告。用户只要求下载、理解或已有内容包排版时，执行对应子技能并在所需结果处结束，不扩大任务。

读取输入清单的schema和状态，不能只凭文件名推断：

| 输入 | 起点 |
| --- | --- |
| URL或本地音视频 | 🎩 circus-conjurer |
| video-fetch/1媒体包，含可用媒体或字幕 | 🤹 circus-juggler；先检查获取状态及范围 |
| circus-juggler/1 materials_ready | 🤹 阅读素材、审阅并finalize |
| circus-juggler/1 complete或partial最终包 | 🎫 circus-ticket；先核验材料与审阅状态 |
| stale、failed、缺文件或不认识的清单 | 查明原因，从对应阶段恢复；不当作可交付内容 |

总入口需要三个子技能。先通过宿主技能列表或本技能同级目录定位各自SKILL.md，进入阶段时才阅读该技能及相关引用；脚本用已确认的技能绝对路径执行。缺少子技能时报告缺少的具体名称，不能调用虚构工具。总入口没有一键命令行脚本：宿主Agent承担文字、画面理解和编辑编排。

## 连续完成三个阶段

**🎩 获取。** 按circus-conjurer执行，读取产物而非只看退出码。URL优先平台/静态提取；browser_required继续用宿主浏览器观察真实播放器，必要时用已有授权的专用只读下载能力。宿主取回的本地文件通过origin-file绑定来源观察与媒体哈希，再验证。没有平台字幕仍可获取视频并进入本地ASR；不触发平台生成转写来替代本地流程。多条同等正文候选需用户选择；登录/验证码/DRM边界沿用子技能和宿主要求。partial可继续分析已取得范围，缺口随交接保留；info_only或失败不能冒充拿到视频。

**🤹 理解。** 将真实媒体清单传给circus-juggler；本地优先、默认auto补字幕缺口，错误/翻译字幕或疑点按子技能处理。先检查所需运行依赖，模型不随技能安装。阅读实际逐字稿、查看实际画面，形成审阅记录、独立画面观察、校正、章节与未解决项，再finalize。materials_ready只是准备完成，不能就此结束完整报告任务。只做过ASR、抽帧或第二次机器识别不能宣称已经看懂、复听或消除疑点。

**🎫 交付。** 用最终manifest交给circus-ticket。Agent依据已读内容编写editorial.json，默认简报、详细章节、必要的观点/边界/应用/问答、关键画面、可检索转写与来源说明；用户不用操作JSON。事实、画面观察和整理者归纳引用真实已审阅证据，不把规划、演示数字或竞争主张改成已验证事实。渲染到独立空目录，实际查看页面并记录能完成的布局/交互检查；默认不嵌入原音视频，打印导出等未经检查的功能不称已验收。

最终交付HTML链接，按需要附Markdown或内容包，说明实际分析范围和影响结论的缺口。报告rendered不升级上游partial；获取complete、理解complete和页面验收是不同状态。默认交付本地文件，发布、上传或外发由用户另行授权。

## 复用与中断恢复

在独立任务目录分别保存获取、理解、报告产物。可用简短progress.md记录原输入、目标/范围、各阶段目录、输入哈希、实际状态、待确认项与下一步；含签名URL或访问证据的材料保持私有。不要写入Cookie或密钥。

恢复时先按子技能核验来源、媒体和封存材料；核验通过才复用。新输入、参数、来源记录或审阅变更使用相应的新目录，不能重写哈希让旧结果通过。已有有效最终内容包时直接交付，不重复下载、全片ASR或重新假称审阅；报告修改也保留旧成品。

网络、ASR疑点和浏览器回退遵守子技能有限重试；可继续的工作先完成。确实缺访问权限、素材、依赖或用户选择时，指出具体阻碍与可恢复步骤；不绕过限制，不无限循环，也不把尚未理解的素材包装成完成报告。

运行依赖继承子技能：Python 3.10+，媒体阶段所需FFmpeg/ffprobe，平台获取所需yt-dlp，本地ASR所需whisper.cpp及多语言模型，以及宿主实际提供的浏览器/图片读取能力。总入口不新增运行库、模型、云API或平台保证。公共发布包只包含技能、模板和代码，不包含任务报告、媒体、逐字稿、模型或会话资料。
