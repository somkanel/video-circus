# 已批准的第一阶段范围

建立可独立使用的 video-fetch，为后续 video-understand 与 video-report
提供可追溯媒体包。独立编写实现；用户给文件或 URL，Agent 根据实际
媒体来源选择下载路径。主流平台通过 yt-dlp；网页嵌入通过静态发现与
宿主浏览器回退。画质默认最高可用，保留已有原语言字幕。

视频号不作为保证覆盖目标。原始输入、下载、完整解码检查与内容一致性
分别核验；不能把 HTML、试看、广告或探测成功当作目标全片。
不复制既有下载 skill 的代码、文档或宣传资产，不加入受限专用后端。

完成条件：脚本和 skill 可独立使用、交接清单稳定、失败有恢复路径，
本地集成测试通过，实际网络验证与未验证平台如实记录。第一阶段可
独立交付，后续阶段不作为它的运行依赖。
